# 히로시마 동선

2026년 10월 15일부터 19일까지 히로시마 여행 일정을 휴대폰에서 보는 정적 웹사이트입니다. 구글 지도 저장 목록을 바탕으로 만들었고, GitHub Pages로 배포합니다.

- 사이트: https://aleph-kim.github.io/travle-plan/
- 숙소: 히로시마시 니시구 히가시칸온마치 1-8 レジデンス東観音

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전체 (HTML, CSS, JS 한 파일) |
| `data/plan.json` | 날짜별 일정, 장소, 식당 후보, 저장 장소 (빌드 스크립트로 생성) |
| `data/weather.json` | 날씨 예보와 날짜 맞바꿈, 비 판정 결과 (GitHub Actions가 생성) |
| `data/i18n.json` | 일정 내용의 영어, 일본어 번역 (한국어 원문이 키) |
| `config.js` | 구글 Maps Embed API 키 |
| `sw.js` | 오프라인용 서비스 워커 |
| `manifest.webmanifest`, `icon-*.png` | 홈 화면 앱(PWA) 설정과 아이콘 |
| `share.png` | 카카오톡 등 링크 공유 미리보기 이미지 |
| `.github/workflows/weather.yml` | 날씨 갱신 작업 |
| `.github/scripts/weather.py` | Open-Meteo 예보 수집, 날짜 맞바꿈과 비 판정 |

## 화면 기능

### 일정
- 상단에 가는 편, 오는 편 항공편과 날짜 탭(15일~19일)
- 날짜마다 제목, 핵심 포인트, 교통과 입장료 합계(식비 제외), 그날 노천탕, 날씨 카드, 시간순 일정
- 일정 카드: 시각, 비용, 장소 설명, 구글 평점과 후기 수, 타베로그 평점, 후기 요약(좋은 점, 아쉬운 점), 구글 지도 링크, 지도 미리보기
- 이동 카드: 교통수단, 요금, 경로 미리보기 (장소 ID 기준)
- 아침 러닝 카드: 숙소에서 출발해 돌아오는 순환 경로
- 하단에 "저장 장소 더보기" (일정에 넣지 않은 저장 장소를 묶어서 표시)

### 현재 일정과 지난 일정
- 오늘 탭을 열면 지금 시각의 일정을 강조하고, 날짜 바 아래로 0.45초 안에 부드럽게 스크롤
- 이미 지난 일정은 "시각, 제목, 완료" 한 줄로 접히고, 왼쪽 초록 진행 선이 지금 일정까지 채워짐
- 지난 날짜를 열면 일정 전체가 완료로 접혀 있음
- 접힌 줄에는 ⌄, 펼친 카드에는 "접기 ⌃"가 보이고, 펼치고 접을 때 애니메이션
- 현재 일정이 화면에서 벗어나거나 다른 날짜를 보고 있으면 하단 캡슐 토스트("지금, 다음 일정, 이동")가 나타나 누르면 지금 일정으로 이동

### 선택지 (식사, 간식, 쇼핑)
- 하나 고르기, 여러 곳 체크 두 종류. 선택은 기기에 저장
- 고르지 않은 선택지는 이름 한 줄로 접혀 있고 ⌄로 펼쳐 봄. 고른 곳만 펼쳐짐
- 펼칠 내용이 없는 선택지(생략)는 꺾쇠 없음
- 식사 추천 형식: 식당 5곳(구글 후기 많은 순, 종류는 다양하게) + 근처 편의점(브랜드, 구글 평점, 주소) + 생략 = 7개
- 식당 이름 뒤에 종류 표기 (예: 다이짱 (야키니쿠))
- 좋은 점 5개, 아쉬운 점은 후기와 확인된 사실(거리, 마감 시각, 결제 방식)로 최대 5개

### 날씨
- 날짜별 날씨 카드: 기온(당일은 지금 기온과 체감), 최고, 최저, 풍속, 습도, 강수 확률, 자외선, 갱신 시각
- 카드를 누르면 시간별 시트: 날씨, 바람, 습도 탭과 가로 스크롤 그래프, 색이 들어간 날씨 아이콘
- 비 판정 기준 이상인 강수 확률은 파란색 표시

### 조작과 화면
- 좌우로 밀어 날짜 이동 (옆 날짜 화면이 미리 채워진 채로 따라옴)
- 화면 맨 위에서 당겨서 새로고침 (iOS 스타일 12개 눈금이 당긴 만큼 채워짐)
- 시트(지도, 날씨, 설정 등)는 아래로 끌어내려 닫기. 안쪽 내용이 스크롤된 상태면 스크롤 먼저
- 처음 열 때 모든 영역에 스켈레톤 표시
- 설정: 언어(한국어, English, 日本語), 인터랙션 효과 켜기/끄기, 다시 불러오기. 설정은 기기에만 저장
- 라이트, 다크 모드 자동

### 다국어
- 화면 문구는 `index.html` 안 사전, 일정 내용은 `data/i18n.json`으로 번역
- 번역이 없는 문장은 한국어로 표시
- 지도 미리보기 언어, 금액 단위, 시간 표기도 언어에 맞춤

## 날씨와 일정 자동 조정

- 날씨는 GitHub Actions가 Open-Meteo 예보를 받아 `data/weather.json` 하나로 저장하고, 모든 접속자가 같은 파일을 읽음
- 오늘과 지난 날짜의 일정은 바꾸지 않음 (그 시점 값으로 고정)
- 맞바꿈 규칙
  - 날씨가 좋아야 하는 미야지마, 오노미치 날에 비가 오면 비와 상관없는 시내 날(16~18일)과 맞바꿈
  - 두 날 모두 비면 미야지마가 맑은 날을 가져감
  - 비 오는 시내 날은 자전거 대신 전차, 히로시마 성 제외, 온천은 라쿠라쿠엔
  - 15일, 19일은 야외 일정만 빼고 시각을 당김
- 내일 이후 일정이 날씨 때문에 바뀌면 처음 볼 때 한 번 안내 시트를 띄움
- 날짜마다 휴무일, 주말 요금, 미야지마 만조 시각 같은 정보를 미리 반영

### 갱신 주기
- 코드를 main에 올릴 때마다 날씨 갱신 실행
- 갱신이 끝나면 1시간 뒤 다음 실행을 스스로 요청 (GitHub 예약 실행은 자주 건너뛰어서 보완). 대기는 항상 하나만 남고, 10월 19일 이후에는 멈춤
- 예약 실행(매시 17분)도 백업으로 유지
- 날씨 작업이 올린 커밋은 다시 작업을 부르지 않아 반복되지 않음

## 오프라인과 업데이트

- 서비스 워커가 화면과 데이터를 보관해 인터넷 없이도 열림
- 앱을 열 때 인터넷이 되면 날씨를 새로 받아 바로 반영 (GitHub API 우선, 실패하면 저장소 원본 주소). 2초 안에 못 받으면 보관본 사용
- 화면 코드나 일정 파일이 바뀌었거나 날씨 때문에 일정이 바뀌면 "새 일정이 있습니다" 시트로 새로고침할지 물음
- 날씨 숫자만 바뀐 경우는 묻지 않고 다음에 열 때 반영
- "나중에"를 눌러도 앱을 완전히 종료했다가 다시 열면 받아 둔 새 버전이 반영됨

## 홈 화면 앱 (iOS 대응)

- 홈 화면에 추가하면 앱처럼 전체 화면으로 실행
- PNG 아이콘(180, 192, 512, maskable), 노치 영역 대응, 확대와 길게 누르기 방지, 스크롤 튕김 방지
- 카카오톡 공유용 제목, 설명, 미리보기 이미지(Open Graph) 설정

## 여행 조건 (일정을 짤 때 지키는 것)

- 매일 아침 러닝, 최대 5km
- 술 마신 뒤 자전거 타지 않기, 택시 안 타기, 가성비 위주 동선
- 장어, 아나고 요리는 제외
- 저녁 순서: 노천탕, 마트에서 장보기, 숙소에 보관, 1차는 밖에서, 2차는 숙소에서

## 운영 원칙

- 일정 변경은 관련 정보(영업시간, 요금, 교통)를 조사해 조율안을 만들고, 확인을 받은 뒤 반영
- 화면 디자인 변경은 시안을 먼저 보여 주고 확인을 받은 뒤 반영
- 확인되지 않은 정보는 "확인 필요"로 표시
- 외부 서비스는 날씨(Open-Meteo)와 구글 지도만 사용. 브라우저에 쓰기 권한 토큰을 두지 않음

## 참고

- `data/plan.json`을 만드는 빌드 스크립트는 이 저장소에 들어 있지 않습니다.
- 구글 Maps Embed API 키는 `config.js`에 있으며, Google Cloud에서 이 사이트 도메인으로만 쓰이도록 제한해야 합니다.
